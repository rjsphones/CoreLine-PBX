# Contributing to CoreLine

CoreLine's application source is private. This public repository accepts contributions to documentation, issue templates, compatibility notes, approved translations, and reproducible testing information.

## Good contributions

- Correct a documentation error
- Improve installation or troubleshooting steps
- Report a reproducible bug
- Document a phone model and firmware combination
- Suggest a clearly scoped feature
- Improve accessibility or wording

## Do not submit

- Decompiled or reverse-engineered CoreLine code
- Private CoreLine source obtained without authorization
- Credentials, private keys, activation codes, or customer data
- Copyrighted firmware, ringtones, backgrounds, or manuals without permission
- Large binaries directly in Git history
- Changes that present planned features as complete

## Documentation pull requests

Keep changes focused. Explain what was wrong, what changed, and how the result was verified. By intentionally submitting material, you confirm you have permission to provide it and allow CoreLine to use and edit it as part of the project, subject to the repository license notice.
