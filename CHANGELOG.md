# Changelog

This file records public CoreLine releases. Dates use `YYYY-MM-DD`.

## Unreleased

- Preparing the public documentation and support repository.
- Continuing remote-access, softphone, provisioning, and reliability testing.

## PBX 0.14.1 — Beta

- Expanded the local administration interface and UCP.
- Added administration login protection.
- Expanded extensions, trunks, routes, IVRs, queues, paging, parking, recordings, and provisioning tools.
- Added CoreLine Connect groundwork and PBX identity information.
- Added Cisco services, XML applications, push groundwork, ringtone lists, and background management.
- Added phone and softphone device views.
- Added system, firewall, Fail2Ban, backup, and diagnostic groundwork.

## Android Softphone 0.1.5 — Beta

- Added direct-server and PBX ID activation modes.
- Added SIP registration, inbound and outbound calls, PCMU audio, DTMF, ringtone, and diagnostics.
- Fixed Android main-thread network errors affecting call, answer, and hang-up actions.

## Windows Softphone — Beta

- Added activation-code setup and SIP calling groundwork.
- Added call controls, DTMF, ringtone, diagnostics, hold, and transfer testing.

Exact Windows version and checksums belong in each GitHub Release rather than this general changelog.
